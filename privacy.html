Privacy policy

Last updated: October 2026.

Rclone Private Media Vault is a personally operated local desktop configuration for Google Drive, not a public cloud service. The owner runs it on personally controlled Windows computers.

Data accessed

With permission from the Google account holder, the configuration accesses files created or explicitly opened through its Google Drive drive.file authorization. This includes file names, metadata, and file contents needed to list, read, create, update and delete files in its dedicated encrypted folder.

Data handling and storage

File contents and file or subfolder names are encrypted on the local PC before Google Drive storage. The top-level folder name may be visible to Google. Encrypted files remain in the account holder's own Google Drive. Unencrypted file data may be temporarily cached on each local PC.

The OAuth refresh tokens and encryption configuration are stored locally and protected by rclone configuration encryption and Windows account-specific data protection. Recoverable backups may be stored separately under the account holder's control.

Sharing and third parties

The configuration has no separate application server or analytics service and does not share Google data with advertisers. Google processes data as the storage and API provider under its applicable terms. The underlying software is locally installed from its respective providers.

Retention and control

The account holder controls file retention, can remove files from their Drive, and can revoke the application's access in Google Account security settings. Locally cached files are subject to the rclone VFS cache settings and the owner's manual cleanup policies.

Contact

For questions about the private application configuration, the account holder can be reached through the support contact shown on the Google OAuth consent screen.
