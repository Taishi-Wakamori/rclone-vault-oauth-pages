Rclone Private Media Vault

This site describes a personal Windows configuration for storing encrypted files on Google Drive using the open-source software rclone and WinFsp.

The configuration mounts an encrypted Google Drive directory as a local Windows drive across the owner's PCs. File contents and names are encrypted by rclone crypt before they are uploaded.

Google Drive authorization uses a desktop OAuth application with the drive.file scope. This is a private configuration and does not offer a hosted upload, download or login service.

Privacy policy

This personal configuration is independent of Google, rclone and WinFsp.
